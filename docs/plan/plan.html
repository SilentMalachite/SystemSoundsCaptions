SystemSoundsCaptions：Java のリアルタイム字幕アプリ

Why · 1 request Java25以上を用いて、macOSやWindows対応。システムに取り入れたファイルやマイク音声をリアルタイムで字幕表示できるアプリを作成したい。jar形式で固めてワンクリックで起動できるようにしたいです。

jar を1つダブルクリックすると、アプリが起動する。

Maven Shade が全クラスとネイティブライブラリを1つの jar に入れる。

これが無いと MP3 を読めない。

Java 25 未満で起動すると、エラーを画面に出して止まる。

マイクの音が3秒間ゼロなら、OS の許可設定を案内する。

リスク jar のダブルクリック起動で macOS が許可ダイアログを出すか、まだ確認していない。最初の試作で確かめる。

ユーザーは小さな操作ウィンドウで音源と言語を選ぶ。

どれも同じ認識処理に入る。

最初の版で、どの言語を選べるようにしますか？

すべての音源は 16 kHz モノラル PCM を同じキューに送る。

開始ボタンは、モデルの読み込みが終わると「停止」に変わる。

システム音声は、ループバック用の入力デバイスから取り込む。

システム音声をどう取り込みますか？
macOS では、ユーザーが BlackHole を入れて「複数出力装置」を作る必要がある。手順を README に書く。デバイスが無いとき、画面にも案内を出す。
macOS 側は Swift の小さなヘルパーが要る。jar 1つという形を保つには、ヘルパーを jar に入れて初回に展開する。

字幕は、他のアプリより前面の半透明ウィンドウに出る。

確定すると白になる。

オーバーレイは確定行を2行まで残し、5秒後に消す。

ユーザーはオーバーレイをドラッグで動かせる。次の起動でも同じ位置に出る。

ユーザーは音声や動画のファイルを開き、再生に合わせて字幕を見る。

どのファイル形式を読めるようにしますか？
4.2 は無くなる。

ファイル音源は、スピーカーと認識処理へ同時に音を送る。

Java Sound で読めない形式は、ffmpeg が PCM に変える。

音声認識は PC の中で動く。初回のあとはネット接続が要らない。

どの認識エンジンを使いますか？
5.1 は 3 秒ごとの区切りになり、灰色の途中結果は出ない。モデルは約 140 MB（base）。
5.2 は無くなり、API キーの設定画面が増える。音声が外部に送られる。

認識スレッドは 0.1 秒ずつ音を読み、途中結果と確定結果を出す。

RecognizerWorker.java:25 · run()

初回の開始で、モデルをユーザーのフォルダにダウンロードする。

モデルをどう配りますか？
5 のダウンロード画面は無くなる。初回に jar からユーザーのフォルダへ展開する。

共有: 1つの音源インターフェースと1つの字幕イベント型。

作らないもの: 翻訳、字幕ファイルの書き出し、インストーラー。

  • 翻訳、話者の区別、SRT の書き出しは作らない。
  • クリックが下のアプリに抜けるオーバーレイは作らない。OS ごとのネイティブ API が要る。
  • jpackage のインストーラーは作らない。配るのは jar 1つだけ。
  • Java ランタイムは同梱しない。ユーザーが Java 25 以上を入れる。
  • Linux 用のネイティブも jar に入るが、テストはしない。
